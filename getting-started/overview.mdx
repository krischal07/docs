  <Tab title="Communication">
    <Info>
      The **Communication** feature requires a connected WhatsApp communication provider. To use this feature and get access, contact the Samparka team.
    </Info>
    
    The **Purchase QR** endpoint lets **POS terminals** create a Samparka *purchase-checkout* session on the fly and receive the QR link in the same HTTP response. The POS renders that link as a QR and prints it on its receipt. The customer scans → WhatsApp flow → Wapio verification → points.
    
    ```mermaid
    sequenceDiagram
      participant POS as POS
      participant SAM as Samparka
      participant CUST as Customer
    
      POS->>SAM: POST { amount, items }
      SAM->>SAM: Create purchase-checkout session
      SAM->>SAM: Wapio signs the QR
      SAM-->>POS: { qr_link }
      POS->>POS: Render link as QR and print on receipt
      CUST->>CUST: Scans QR on receipt
      CUST->>SAM: Opens WhatsApp deep link & claims
      SAM->>SAM: Verification + completion orchestrator
      SAM-->>CUST: Points awarded
    ```

    ## How It Works
    
    ```mermaid
    stateDiagram-v2
      [*] --> CREATED
      CREATED --> QR_GENERATED: ensureQrGenerated
      QR_GENERATED --> WAITING_FOR_CUSTOMER_CLAIM: customer waits
      WAITING_FOR_CUSTOMER_CLAIM --> CLAIMED: customer scans
      CLAIMED --> POINTS_AWARDED
      POINTS_AWARDED --> [*]
      QR_GENERATED --> QR_GENERATED: POS retry while pending (same QR, 200)
    ```
